## Project Overview

This project explores AI-assisted test automation using Playwright Agents, GitHub Copilot, TypeScript, and Playwright Test on the Sauce Demo demo e-commerce application.

The project explores the following Playwright Agents:

- **Planner Agent** – Used to generate a structured test plan covering key application workflows and expected results.
- **Generator Agent** – Used to generate Playwright test scripts based on the generated test plan.
- **Healer Agent** – Included in the project workflow to explore AI-assisted test diagnosis and repair.

**GitHub Copilot** was used as part of the AI-assisted development workflow to support test creation and refinement.

The test scenarios cover user authentication, shopping cart operations, product sorting, and the checkout process.

The goal of this project is to gain practical experience with AI-assisted test planning and generation while understanding the importance of reviewing, debugging, and validating generated tests.

**Application under test:** [Sauce Demo](https://www.saucedemo.com/)

## Technology Stack

- **Playwright Test** – Browser automation and test execution
- **TypeScript** – Test scripting
- **Node.js and npm** – Runtime and package management
- **Playwright Planner Agent** – Test planning
- **Playwright Generator Agent** – Test generation
- **Playwright Healer Agent** – AI-assisted test diagnosis and repair
- **GitHub Copilot** – AI-assisted coding and test refinement
- **Git and GitHub** – Version control and project documentation
